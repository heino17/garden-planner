# **🌱 Julia's Gartenplaner – Datenbank‑Demos**
### readme: 🇩🇪 DE, 🇺🇸 US, 🇷🇺 RU, 🇪🇸 ES, 🇫🇷 FR, 🇯🇵 JP, 🇰🇷 KR, 🇨🇳 zh-CN

## 🇩🇪 **Deutsch (DE)**  
In den Datenbank-Demos sind ausschließlich die `Pflanzennamen` in die jeweilige Sprache übersetzt.  
Alles Weitere liegt in Deiner Hand! :)  

Um eine dieser Datenbanken für Dich zu verwenden, gehst Du wie folgt vor:  

**Weg 1**:  
- Benenne die Datenbank Deiner Wahl um in `pflanzen.js` und speichere diese im Hauptordner, den selben Ordner in dem die `gartenplaner.html` liegt.  

**Weg 2**:  
- Öffne/starte die Datei `datenbank_bearbeiten.html` und öffne per `Andere Datenbank öffnen` die Demo-Datenbank Deiner Wahl.  
- Wenn die Demo-Datenbank geladen wurde, verwende `Datenbank speichern` und speichere die Datei im Hauptordner, als `pflanzen.js`!  
  - Dabei ersetzt Du die ursprüngliche `pflanzen.js`! So wird aus z.B. `pflanzen_fr_demo.js` → `pflanzen.js`  

**Sobald Du eine Demo-Datenbank Deiner Wahl als `pflanzen.js` gespeichert hast,**  
**stehen *🌱 Julia's Pflanzen-Datenbank* und *🌱 Julia's Gartenplaner* in dieser Sprache zur Verfügung!***

## **🌱 Julia’s Garden Planner – Database Demos**

## 🇺🇸 **American (en)**  
In the database demos, only the `plant names` are translated into the respective language.  
Everything else is up to you! :)  

To use one of these databases, proceed as follows:  

**Method 1**:  
- Rename the database of your choice to `pflanzen.js` and save it in the main folder — the same folder where `gartenplaner.html` is located.  

**Method 2**:  
- Open/start the file `datenbank_bearbeiten.html` and use `Open another database` to load the demo database of your choice.  
- Once the demo database is loaded, use `Save database` and save the file in the main folder as `pflanzen.js`!  
  - This replaces the original `pflanzen.js`. For example: `pflanzen_fr_demo.js` → `pflanzen.js`  

**Once you have saved a demo database of your choice as `pflanzen.js`,**  
**both *🌱 Julia's Plant Database* and *🌱 Julia's Garden Planner* will be available in that language!***

## **🌱 Julia’s ガーデンプランナー – データベースデモ**

## 🇯🇵 **日本語 (JP)**  
データベースデモでは、`植物名`のみが各言語に翻訳されています。  
その他はあなた次第です！ :)  

これらのデータベースを使用するには、次の手順に従います：  

**方法 1**:  
- 選んだデータベースを `pflanzen.js` にリネームし、`gartenplaner.html` と同じメインフォルダに保存します。  

**方法 2**:  
- `datenbank_bearbeiten.html` を開き、`別のデータベースを開く` から希望するデモデータベースを読み込みます。  
- デモデータベースが読み込まれたら、`データベースを保存` を使ってメインフォルダに `pflanzen.js` として保存します。  
  - これにより元の `pflanzen.js` が置き換えられます。例：`pflanzen_fr_demo.js` → `pflanzen.js`  

**デモデータベースを `pflanzen.js` として保存すると、**  
***🌱 Julia の植物データベース* と *🌱 Julia のガーデンプランナー* がその言語で利用可能になります！***

## **🌱 Julia’s 정원 플래너 – 데이터베이스 데모**

## 🇰🇷 **한국어 (KR)**  
데이터베이스 데모에서는 `식물 이름`만 해당 언어로 번역되어 있습니다.  
나머지는 모두 당신에게 달려 있습니다! :)  

이 데이터베이스 중 하나를 사용하려면 다음과 같이 하세요:  

**방법 1**:  
- 원하는 데이터베이스의 이름을 `pflanzen.js`로 변경하고 `gartenplaner.html`이 있는 동일한 메인 폴더에 저장하세요.  

**방법 2**:  
- `datenbank_bearbeiten.html` 파일을 열고 `다른 데이터베이스 열기`를 통해 원하는 데모 데이터베이스를 불러옵니다.  
- 데모 데이터베이스가 로드되면 `데이터베이스 저장`을 사용하여 메인 폴더에 `pflanzen.js`로 저장하세요.  
  - 이렇게 하면 기존 `pflanzen.js`가 대체됩니다. 예: `pflanzen_fr_demo.js` → `pflanzen.js`  

**데모 데이터베이스를 `pflanzen.js`로 저장하면,**  
***🌱 Julia의 식물 데이터베이스*와 *🌱 Julia의 정원 플래너*를 해당 언어로 사용할 수 있습니다!***
